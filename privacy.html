2. 健康に関する情報

ケガ歴や持病など健康に関する情報は、安全にトレーニングを進めるために必要な範囲で、ご本人の同意を得て取得します。ご本人が公式LINE、面談の予約フォーム、面談で伝えてくださった情報は、本サービスのために使うことに同意いただいたものとして扱います。当方は医師ではないため、診断や治療は行いません。

3. 利用目的

  1. コーチングを提供するため（メニューの作成と調整、日報やフォームの動画へのフィードバック、面談）
  2. 安全にトレーニングを進めるため（体調やケガの確認、医療機関の受診のおすすめ）
  3. お申し込みの確認、入金の確認、返金のため
  4. お問い合わせへの回答と、本サービスのご案内（無料プログラムやコーチングの募集など）をお送りするため
  5. 本サービスを良くするため（記録を、個人が分からない形にまとめて使います）
  6. 変化の記録や感想を紹介するため（ご本人の同意を得た場合に限り、同意いただいた範囲で行います。匿名を選べます）

4. 第三者への提供

法令で認められる場合を除き、ご本人の同意なく、個人情報を第三者に提供しません。

5. 外部のサービスの利用

本サービスでは、次の外部のサービスを使います。これらのサービスを通じて送られる情報は、各社の方針にも従って取り扱われます。

  • LINE（LINEヤフー株式会社、日本）：連絡、日報や動画の受け取り
  • Google Meet・Googleカレンダー（Google LLC、米国）：面談と、無料面談の予約（予約フォームで伺った内容を含みます）
  • YouTube（Google LLC、米国）：実演動画の公開（限定公開）
  • GitHub Pages（GitHub, Inc.、米国）：このページと記録用のページの公開（ページを開いたときに、IPアドレスが記録されます）
  • Google Fonts（Google LLC、米国）：ページの文字の表示（ページを開いたときに、IPアドレスなどが送られます）

米国の事業者のサービスを使うにあたり、米国の個人情報の保護に関する制度を、個人情報保護委員会が公表している情報で確認しています。
